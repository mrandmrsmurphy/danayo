## Notes
- 形聲 (OC \*bɯnʔ): semantic [[Radical 061|忄]] ("heart") + phonetic [[奔]] (OC \*pɯːn) — "to resent." The character's primary phonetic ancestor is [[賁]] (whose own etymology names 卉 + 貝), but 賁 was itself historically borrowed to write 奔, and Wiktionary's own derivation table names 奔 specifically as the phonetic component for this bɯn-family reading, matching 憤's OC value directly.
