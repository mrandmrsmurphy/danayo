## Notes
- 形声 (OC \*kʰloːnʔ, per Shuowen): semantic [[Radical 076|欠]] ("lacking, desire") + phonetic 窾 (no character page exists for it in this vault) — "a clause, item, article" (of a document or agreement). Note: the character's *older* ancestor form 歀 (a distinct reading, kuài, "desire") used phonetic 柰 instead — an unrelated etymon that graphically merged into the modern 款 glyph; 柰's own OC (\*naːds) doesn't match 款's actual reading at all, so 窾 (an exact OC match) is the correct phonetic to cite for this character as used today.
