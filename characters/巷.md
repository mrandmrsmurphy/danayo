## Notes
- 形声 (MC ɣʌŋ, 匣母江韻): semantic [[己]] ("self, enclosure" — here likely a graphic simplification tracing the winding boundary between dwelling compounds) + phonetic [[共 (char)|共]] — alley, lane; the classical distinction is that a straight thoroughfare is 街 while a curved one is 巷.
- [SKIP-2-4-5](lookup/SKIP/SKIP-2/SKIP-2-4-5.md) ([Stroke 09](lookup/Stroke/Stroke%2009.md)) — SKIP code confirmed against WWWJDIC directly (the vault's own derivation guess, 2-6-3, was wrong).
- 1898th most used character in Classical Chinese (see [[lookup/CC/CC 1000]]). Ancient [[Lookup/CC/initials/聲 匣|ɣ]] + [[Lookup/CC/finals/韻 江|ɣʌŋ]] → [ㄏㄚㄫ](syllables/ㄏㄚㄫ.md) — the same derivation path as [[項 (char)|項]], [[行 (char)|行]], [[幸]], and several others in this large ㄏㄚㄫ cluster; a real, expected collision, not an error.
- [HSK Old 6](lookup/HSK/Old%20HSK%206.md) rank 722, [Jinmeiyō](lookup/Japanese/Jinmeiyō.md) (permitted for Japanese given names, though not part of the core 常用漢字/Jōyō list — hence `joyo_level: 日本人名用漢字`), [Korean HS](lookup/Korean/Korean%20HS.md).
- **Correction (2026-09-19)**: this character had been wrongly treated as an alias/redirect of [[巻 (char)|巻]] ("roll, scroll") across several lookup files (`characters/巻 (char).md`'s own `aliases`, `Korean HS.md`, `Jinmeiyō.md`, and both `Old HSK 3.md`/`Old HSK 6.md`) — a visual-similarity mix-up between two genuinely unrelated characters (different radical, different Middle Chinese origin, different meaning in every source language). All corrected to point here instead. Previously described only in prose on [[港]]'s own page (its real phonetic component) with no character page of its own; this page fills that long-standing gap.
