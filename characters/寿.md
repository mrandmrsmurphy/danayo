## Notes
- 形声 (OC \*djus): semantic 耂 ("old") + phonetic 𢏚 — already paired this way in bronze-script forms, sometimes bearing decorative 口 and/or 又 (the 又 became [[Radical 041|寸]] in the modern form) — "longevity; long life." (Neither 耂 nor 𢏚 has its own character page in this vault; the vault had previously stored this field as `會意`, but Wiktionary's bronze-inscription analysis is unambiguously phono-semantic, not a simple compound ideograph, so the field was corrected.)
- 躊 (足 + 壽) is aliased here, not given its own page: it's the phonetic host for the 聯綿詞 [[躊躇]] (Dan'a'yo [[寿着]]), where 足 was added purely as a category marker (pacing/hesitation) and never occurs independently of that one word.
