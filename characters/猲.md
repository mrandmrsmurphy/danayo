## Notes
- 形声: semantic [[Radical 094|犬]] ("dog") + phonetic [喝 (char)](characters/喝%20(char).md) (sharing 猲's true phonetic root 曷, which has no independent page). This is one of several distinct pronunciations of a polysemous glyph — this page models the `xiē` reading, "only used in" the compounds 猲獢 ("short-mouthed hunting dog") and 猲狚 ("a legendary giant red wolf," matching `japanese_native: おおかみ`); a different reading (`gé`) instead means "flame/smoke from fire," which must not be conflated with this page's sense.
