## Notes
- 形声 (per Shuowen, 从夭賁省聲): [[Radical 037|大]] (originally 夭, "a running person, arms swinging") + phonetic [[卉]] (an abbreviation of [[賁]], which carries an alternate reading bēn identical to 奔's, as in 虎賁 "brave warriors") — "to run, dash, flee." 犇 (three 牛 "oxen," 會意, "to run wildly like cattle stampeding") is a distinct, rarer character occasionally used interchangeably with 奔 in the same sense, kept as an alias.
- [SKIP-2-3-6](lookup/SKIP/SKIP-2/SKIP-2-3-6.md) ([Stroke 9](lookup/Stroke/Stroke%209.md))
- 619th most used character in Classical Chinese. Ancient [[Lookup/CC/initials/聲 幫|p]] + [[Lookup/CC/finals/韻 魂|uən]] → [ㄅㄛㄋ](syllables/ㄅㄛㄋ.md)
