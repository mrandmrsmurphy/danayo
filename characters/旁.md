## Notes
- 形声 (OC *baŋ): semantic [[同]] ("together, same") + phonetic [[方]] (OC *paŋ) — side, beside, close by; also a technical term for the right-hand component of a compound character (偏旁, where 偏 traditionally names the left component), a sense already reflected in this vault's own [[words/旁胱|旁胱]]. 膀 ("shoulder, bladder"), which has no independent page in this vault, is a fully distinct character sharing only the páng reading — 旁 is used as a phonetic stand-in for it in 旁胱's own coinage, which appears to be the source of a prior editor mistakenly listing 膀 (and its own further variants 髈, 𦜅, 𦜶) as aliases of 旁; none is dual-source confirmed as a genuine variant of 旁 itself, so all four were removed. A stray Hyōgai redirect and a stray Korean Name link built on the same false premise were also corrected.
