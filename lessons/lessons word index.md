# Lessons: Word Index

This index records which words a learner should know by the end of each lesson of the [[lesson-outline]].  A word is "assigned" to the lesson in which it is first taught.  The character equivalent is [[lessons characters index]].

## Goal
By the end of the course the learner should have met many, many words, built from the characters assigned in [[lessons characters index]].  The outline plans 20 to 50 core words per lesson, each with an example sentence.

85 words are assigned so far: 55 in [[Lesson 03]] and 30 in [[Lesson 04]].
