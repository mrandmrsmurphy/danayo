## Notes
- [野](characters/野.md) "wild, field" + [菜](characters/菜.md) "vegetable, dish" — "edible wild herbs, vegetables."

Mandarin yěcài, cantonese je5 coi3, japanese やさい, korean 야채, and vietnamese dã thái are all directly attested standard readings, matching both characters' own stored values exactly. `kwin` is true: Dan'a'yo 야채 matches Sino-Korean 야채 exactly. Part of a genuine Dan'a'yo homophone with [[夜叉]] ("yaksha, a fierce demon") — coincidental, unrelated in meaning; previously uncalled-out on either page, now added reciprocally.

Both character-page citations already correctly present. 菜's own `stand_in` is this exact word (野菜), so 菜 is legitimized as an independent Dan'a'yo entry specifically by 野菜; 野's own `stand_in` is instead 田野, so this word does not legitimize 野.
