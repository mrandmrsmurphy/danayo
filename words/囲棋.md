## Notes
- [囲](../characters/囲.md) "encircle" + [棋](../characters/棋.md) "chess, strategy game" — the character actually referenced here is [碁](../characters/碁.md) ("Go stone"), for which 棋 is a same-Dan'a'yo-reading (gi/기/ㄍㄧ) phonetic substitute; 碁's own `stand_in` field is this word itself (棋's own stand-in is the unrelated [[将棋]]). 囲's own stand-in is [[包囲]].

囲棋 names the board game Go (圍棋), literally "encircling chess."

Japanese いご (using 碁's own GO reading, confirming 碁's identity as the true referent), Korean 위기, Mandarin wéiqí, and Cantonese wai4 kei4 are all standard readings, matching Dan'a'yo's own reading exactly (`kwin: true`). [[囲碁]] is a near-duplicate entry for the same game using 碁 directly rather than the 棋 substitute — the two share an identical Dan'a'yo reading (注音 ㄨㄧㄍㄧ), though 囲碁's own page has some inconsistent fields (e.g. an unexplained leading apostrophe in its 羅馬字) that may merit a closer look in a future pass.
