## Notes
- [酒](characters/酒.md) "alcohol, liquor" + [精](characters/精.md) "essence, spirit" — "alcohol, ethanol."

Mandarin jiǔjīng, cantonese zau2 zing1, and japanese しゅせい are all directly attested standard readings. **Found and fixed a real-equivalent-instead-of-own-reading bug on `korean`**: 알코올 (a katakana-style transliteration of the English loanword "alcohol") replaced with the honest compositional 주정 (酒's own 주 + 精's own 정). **Found and fixed a malformed/real-equivalent `japanese`/`vietnamese`**: japanese had a comma-mashed value pairing しゅせい with the native loanword アルコール (trimmed to しゅせい); vietnamese had a comma-mashed value pairing native "rượu"/"rượu cồn" (both everyday words for alcohol) rather than the honest compositional pairing — corrected to "tửu tinh" (酒's own tửu + 精's own tinh). `kwin` is false: Dan'a'yo 줏정 diverges from Sino-Korean 주정 entirely. **Found a genuine homophone with [[調整]]** ("adjust, transfer"), previously uncalled-out on either page — added reciprocal callouts to both.

Both character-page citations already correctly present. 酒's own `stand_in` is this exact word (酒精), so 酒 is legitimized as an independent Dan'a'yo entry specifically by 酒精; 精's own `stand_in` is instead 精神, so this word does not legitimize 精.
