## Notes
- [新 (char)](../characters/新%20(char).md) "new" + [西](../characters/西.md) "west" + [蘭](../characters/蘭.md) "orchid (for the sound 'lan')" — literally "New West-lan[d]," a calque-plus-phonetic rendering of English "New Zealand" ("Zealand" broken into 西蘭, using 西's meaning "west" plus 蘭's sound).

新西蘭/新西兰 is the standard Chinese name for New Zealand, following the same "new/西蘭" calque-plus-transliteration pattern used across the Sinosphere for this country name specifically.

Mandarin Xīn Xīlán and Cantonese san1 sai1 laan4 are both the real, standard names. Korean 신서란 (sinseoran) is the fully compositional Sino-Korean reading; modern Korean instead almost always uses the transliteration 뉴질랜드 (nyujillaendeu), with 신서란 essentially unused in practice — kept here per this vault's standing compositional-reading convention regardless of real-world frequency. Japanese instead stores ニュージーランド (nyūjīrando), the actual standard Japanese name — Japanese does not use a kanji calque for this particular country, unlike Chinese/Korean, so the transliteration is the only real option here (paralleling how Periodic Table words store the real scientific term rather than force a compositional reading when no real compositional form exists). Vietnamese Tân Tây Lan is a real, historically attested Sino-Vietnamese name (composed the same way: tân "new" + tây "west" + lan, the sound-value of 蘭) — now largely obsolete in everyday use, replaced by the transliteration Niu Di-lân, but still found in older texts. `kwin` is false: Dan'a'yo 신세란 diverges from Sino-Korean 신서란 in the second syllable (세 vs. 서). No Dan'a'yo homophones (注音 ㄙㄧㄋㄙㄝㄧㄌㄚㄋ unique among both words and characters).
