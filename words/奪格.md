## Notes
- [奪](../characters/奪.md) "seize, take away" + [格 (char)](../characters/格%20(char).md) "case (grammatical)" — the case marking a source from which something is taken or departs, part of the same matched set of case-term coinages as [[共格]]/[[具格]]/[[処格]]/[[向格]]/[[呼格]]. `vietnamese: đoạt cách` is compositional; as with its siblings, no fixed attestation was found for this specific grammatical-case coinage (domain knowledge, this session's search quota exhausted).

The grammar book's own comparison table glosses this same case (marked in Dan'a'yo by 由) as 離格 ("departure case") rather than 奪格, an internal naming inconsistency within the source text — both terms describe the same case and are interchangeable, with 奪格 being the broken link this entry resolves.
