## Notes
- [棕](../characters/棕.md) "palm; brown" + [[枝]] "foliage" — this word is 棕's own `stand_in`, since 棕 is too bounded to stand alone.

The character used for the second syllable here, 枝, is a graphic/phonetic substitute — this vault has no character page for the "true" palm-tree partner characters 櫚/榈 (real Mandarin lǘ, matching this word's own ㄌ⼄/lyo reading), so 枝 stands in for them the same way [[牡厉]] stands in for 牡蠣's unavailable 蠣. Real-world Mandarin also has a genuinely distinct word 棕枝 (zōngzhī, "palm branch/frond," using 枝's own real "branch" reading) — see [[棕枝主日]] ("Palm Sunday") for that separate sense; this word's own stored readings track "palm tree" (zōnglǚ), not "palm branch."
