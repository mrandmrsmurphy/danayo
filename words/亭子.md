## Notes
- [亭](../characters/亭.md) "pavilion" + [子](../characters/子.md) (noun suffix) — tíngzi, the standard everyday Mandarin word for a garden pavilion/kiosk, matching 亭's own Korean native gloss 정자 ("pavilion"). `vietnamese: đình tử` is compositional; no fixed idiom was found via web search, and standard Vietnamese instead uses đình alone (as in Lan Đình, the famous "Orchid Pavilion") for this architectural concept — documented as a gap rather than fabricated.

**Real bug found and fixed**: this page and [[停止]] each claimed to be the other's homophone, but their 注音 actually differ (亭子 ends ㄐㄜ, 停止 ends ㄐㄧ) — not homophones at all. Removed the false claim here and on [[停止]]'s own page.

Legitimizing note: 亭's own `stand_in` is this exact compound, so 亭 is legitimized as an independent Dan'a'yo entry specifically by this word; 子's own `stand_in` is [[児子]], not this word, so transitivity fails and `#cranberry` does not apply.
