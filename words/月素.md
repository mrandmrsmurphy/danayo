## Notes
- [月 (char)](../characters/月%20(char).md) "moon" + [素](../characters/素.md) "element, stuff" — "moon element," selenium.

月素 is the Dan'a'yo name for selenium (Se), built on the same etymology as the English word: selenium takes its name from Greek *selene*, "moon". The Dan'a'yo name uses 月 "moon" plus the element classifier 素, rather than the Chinese novel character 硒 (listed as an alias). It is a Dan'a'yo-internal coinage, in the same vein as [[日素]] for helium.

The recorded readings are the languages' own names for the element rather than compositional readings of 月素: Mandarin xī (硒), Cantonese sai1, Japanese セレン (seren), Korean 셀레늄 (sellenyum), and Vietnamese selen. For the full system of element names, see [Periodic Table](../lexipedia/Periodic%20Table.md).
