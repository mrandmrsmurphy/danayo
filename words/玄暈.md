## Notes
- [玄](../characters/玄%20(char).md) "deep, profound, mysterious" + [暈](../characters/暈.md) "dizzy, blurry" — 暈's own stand-in is this exact compound, but 玄's own is itself; transitivity fails, so `#cranberry` does not apply, though 暈 is legitimized as an independent Dan'a'yo entry specifically by this word. The real word is properly written 眩暈; 眩 has no vault page, so 玄 substitutes, and both `mandarin`/`cantonese`/`korean`/`vietnamese` correctly use 眩's own divergent real readings (xuàn/jyun6/현/huyễn) rather than 玄's own (xuán/jyun4/현/huyền) — a polyphonic alias-divergence, matching the pattern already seen on [[無然]]/[[片仮名]]/[[版画]]/[[狐猿]]/[[猿痘]]/[[猶予]].

玄暈 (properly 眩暈) means dizziness, vertigo.
