## Notes
- [武 (char)](../characters/武%20(char).md) "military" + [士 (char)](../characters/士%20(char).md) "scholar, gentleman" — literally "military gentleman," the samurai/warrior class of pre-modern Japan.

Mandarin wǔshì, Cantonese mou5 si6, Japanese ぶし (bushi), Korean 무사, and Vietnamese võ sĩ are all standard, fully compositional readings, matching 武's and 士's own stored citations exactly. **Found and fixed a real bug**: `注音` was stored as ㄇㄩㄙㄚㄧ, using ㄩ instead of ㄨ for the first syllable — inconsistent with the word's own 羅馬字 (musai) and 諺文 (무새), and inconsistent with the sibling word [[武士道]] ("bushido"), which already correctly uses ㄨ for the same 武 syllable. Corrected to ㄇㄨㄙㄚㄧ, and the same stale reading fixed on both characters' own `## Words` backlinks.

`kwin` is false: 武 alone is kwin-true, but 士 independently diverges from Korean on its own character page, which alone is enough to make the AND-rule false. No homophones (注音 ㄇㄨㄙㄚㄧ unique among both words and characters).
