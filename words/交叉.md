## Notes
- [交 (char)](../characters/交%20(char).md) "to cross, exchange" + [叉 (char)](../characters/叉%20(char).md) "fork, prong" — giao thoa, directly attested Sino-Vietnamese (confirmed via web search) for "to intersect, cross," most familiar today in the physics term giao thoa sóng, "wave interference." This finding also surfaced a gap on [[叉 (char)]]'s own page: its vietnamese field only listed xoa, missing this independently attested thoa reading — added.

Real Japanese conflates this word with 交差 (both read こうさ, both meaning "intersect/crossing," e.g. 交差点 "intersection"), but Dan'a'yo keeps them fully distinct: [[交差]] has been repurposed in this vault for an unrelated sense, "to report in, get debriefed," while 交叉 retains the real "intersect, cross" meaning. `kwin` is false: Dan'a'yo 걋채 diverges from Sino-Korean 교차 in the first syllable's coda — the same divergence pattern shared with its real homophone [[教材]] ("teaching materials").

**Real content bugs found and fixed**: `japanese` was stored in obsolete historical kana orthography (かうさ, kau-sa) rather than modern standard kana こうさ, despite the Notes above already correctly using こうさ throughout — corrected. Found a missing citation on `交(char).md` (交叉 was cited on 叉 but not 交) and upgraded a bare-format citation on `叉(char).md` — both fixed.
