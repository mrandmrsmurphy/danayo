## Notes
- [乾](../characters/乾%20(char).md) "dry" + [燥](../characters/燥.md) "dry, parched" + [机](../characters/机.md) "machine" — "drying machine," built on the word [[乾燥]] ("dry"). 燥's own `stand_in` is [[乾燥]], which this word contains rather than replaces; 乾's is itself and 机's is [[机会]], so 乾燥机 is an independent compound.

乾燥机 is a clothes dryer, or more generally any machine that dries (a dehydrator). Mandarin gānzàojī, Cantonese gon1 cou3 gei1, Japanese かんそうき and Korean 건조기 all use these characters. Wiktionary lists the sense as "drying machine; dehydrator; dryer".

Compare [[机器]] (machine).
