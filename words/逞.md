## Notes
- [逞 (char)](characters/逞%20(char).md) "indulge, brag" — 逞 stands alone as a word in Dan'a'yo.

Mandarin chěng and cantonese cing2 are directly attested standard readings, matching the character's own stored values exactly. **Found and fixed a korean reading bug on both this page and 逞(char).md itself**: the stored value 령 used an ㄹ-initial, structurally incompatible with 逞's own Middle Chinese initial 徹 (ʈʰ), which never surfaces as ㄹ in Sino-Korean — corrected to 정 by direct analogy with [[偵]] (same MC initial ʈʰ and final iᴇŋ, also read 정). Vietnamese sính is the character's own stored reading. `kwin` is false: Dan'a'yo 칭 diverges from Sino-Korean 정 entirely. Confirmed the existing homophone callout with [[請]] is already correctly reciprocal.

**Found and fixed a missing "(stand-in for 逞)" annotation** on 逞(char).md's own citation. 逞 (char)'s own `stand_in` is this exact word (逞, itself), so 逞 (char) is legitimized as an independent Dan'a'yo entry by this same word.
