## Notes
- [柏 (char)](../characters/柏%20(char).md) + [克 (char)](../characters/克%20(char).md) "gram; overcome" + [金 (char)](../characters/金%20(char).md) "metal" — a transliteration of *Berkeley*, after the University of California, Berkeley, where the element was discovered, continuing this vault's avoid-the-real-element-character convention (the actual Chinese chemistry character for berkelium is 锫, péi, unrelated to any of this word's three constituent characters) — the same pattern as [[丹金]]/[[居里金]]/[[愛因金]]/[[奥加素]]/[[田納素]]/[[莫斯素]]/[[日本素]] elsewhere in this series.

柏克 renders only the first two syllables of the full transliteration 柏克萊, the standard Mandarin transliteration of "Berkeley" — the same truncate-to-two-syllables pattern already seen on [[愛因金]] (Einstein), and here 柏 additionally carries its own toponymic precedent: the same character (read bó in this proper-noun role, as opposed to its "cypress tree" reading bǎi) opens 柏林 (Bólín, "Berlin"), the standard transliteration for a different German/American place name entirely — a coincidental character reuse across two unrelated toponyms rather than any shared etymology. Mandarin/Cantonese here are the plain compositional concatenation of the three constituent characters' own readings (bókèjīn/paak3 hak1 gam1), not the real element name.

Japanese and Korean both borrow the IUPAC scientific name wholesale as a loanword (バークリウム, 버클륨), the same pattern established across this whole series. Vietnamese similarly nativizes the international name directly as Beckeli, continuing the series' "-i" ending pattern already seen on [[日本素]]/[[居里金]]/[[愛因金]]. `kwin` is false, following the same AND-rule exception already documented on [[丹金]]/[[居里金]]/[[愛因金]]: the authoritative test is a plain string comparison of 諺文 (뱍쿡김) against `korean` (버클륨), which plainly differ.
