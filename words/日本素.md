## Notes
- [日 (char)](../characters/日%20(char).md) "sun" + [本 (char)](../characters/本%20(char).md) "root, origin" + [素](../characters/素.md) "element" — together, [[日本]] "Japan" + the element suffix.

Unlike most of this row, 日本素 is a calque rather than a sound transliteration: element 113 was discovered at RIKEN and named *nihonium* directly after Japan (Nihon), so this entry translates the etymology itself rather than transliterating the IUPAC syllables — the same logic as [[茜素]] (rubidium), which calques the Latin root instead of transliterating it. Every other source language instead borrows the IUPAC name wholesale as a loanword (Japanese ニホニウム, Korean 니호늄), making this one of the few elements in the table with no real-world CJKV precedent to follow or split the difference between.

Nihonium holds a special place in the table's history: it is the first element ever discovered in Asia, credited to the RIKEN team led by Morita Kōsuke after experiments running from 2003, officially recognized in 2015 and named in November 2016. Only a handful of atoms have ever been observed, decaying within seconds. Its discovery ended a long run in which every named element had been found in Europe or America — a point of considerable pride in Japanese science, reflected in the choice to name it after the country itself.

The real Chinese element name is 鿭/鉨 (nǐ), adopted 2017: 金 (metal semantic) + 尔 phonetic, which the coiners described as a 省声 (reduced-phonetic) form of 你 nǐ — the sound chosen to echo *Nihon*, so even the single-character name is, like 日本素 itself, a Japan-reference rather than a neutral transliteration. Per this series' convention the `mandarin`/`cantonese` fields hold the avoided real element character's reading: `nǐ` is the officially promulgated pronunciation; `nei5` is extended by convention from 你 (the full form of the reduced phonetic), since no Cantonese reading of 鿭 itself is independently attested in dictionary sources — documented here as extension, not verification, per the precedent set with [[邁金]] (meitnerium). (A caution: the pre-existing character 鉨 is historically a variant of 璽 "imperial seal," saai2 in Cantonese — an unrelated reading that does not apply to the element name.) Vietnamese uses *Nihoni*, continuing this series' "-i" pattern (Moscovi, Tennessi, etc.).
