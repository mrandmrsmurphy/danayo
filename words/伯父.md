## Notes
- [伯](../characters/伯.md) "father's older brother" + [父](../characters/父.md) "father" (honorific extension) — "paternal uncle, older." Both `japanese: おじ` (a valid jukujikun reading alongside the more formal はくふ, matching the native reading already chosen for [[伯母]]'s おば) and `vietnamese: bá phụ` are directly attested (confirmed via web search) — bá phụ specifically distinguishes the father's *older* brother from thúc phụ (叔父, the younger brother). `kwin` is false: Dan'a'yo 박부 diverges from Sino-Korean 백부 via the AND-rule, since 伯's own field independently diverges (despite 父 itself being `kwin: true`). No homophones (注音 ㄅㄚㄎㄅㄨ unique among both words and characters). Legitimizing note: 伯's own `stand_in` is this exact compound, so 伯 is legitimized as an independent Dan'a'yo entry specifically by this word (not by [[伯伯]], [[伯母]], or [[伯爵]], which merely use the character once already legitimized).
