## Notes

**茜素** is a binomial neologism for the element **Rubidium** (Atomic Number: 37). It utilizes the character for the Madder plant (**茜**) to calque the Latin root _rubidus_ (deep red), referencing the element's discovery via spectroscopy.

### Logic Breakdown:
- **Spectral Root:** Rubidium is defined by its [deep red spectral signature](https://en.wikipedia.org/wiki/Rubidium#History). **[茜](../characters/茜.md)** is the classical CJKV term for the deepest natural red dye.
- **Functional Descriptor:** The use of **[素](../characters/素.md)** (Element/Essence) categorizes it alongside other elements defined by their fundamental chemical properties.
- **Single-Character Symbol:** **茜** (Q).

No cranberry (茜's own stand-in is [[茜草]], 素's is [[要素]]). Mandarin rú/cantonese jyu4 (real element name 铷), korean 루비듐, japanese ルビジウム, and vietnamese rubiđi are all legitimate real international element names, per established periodic-table-neologism convention — not bugs.
