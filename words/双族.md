## Notes
- [双](../characters/双%20(char).md) "double, pair" + [族](../characters/族.md) "tribe, clan" — "the Double Tribe, Joseph." Their own `stand_in` values: 双's is itself; 族's is [[家族]]; none points here, so 双族 is an independent compound.

双族 is the tribe of Joseph, Rachel's firstborn, whose name means "he adds" (Genesis 30:24). It is a Dan'a'yo **neologism**, "Double Tribe," because Joseph's two sons each became a tribe, a double portion (Genesis 48:5): [[忘族]] (Manasseh) and [[豊族]] (Ephraim), each a [[半族]]. The character 双 has the alias 雙, so the traditional spelling is accepted. Compare [[右族]] (Benjamin). See [[基督敎]].

- Hebrew name: יוֹסֵף (Yosef) (注音 ·⼄ㄙㄝㄆ).
