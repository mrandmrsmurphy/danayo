## Notes
- [愛 (char)](../characters/愛%20(char).md) "love" + [因](../characters/因.md) "cause" + [金 (char)](../characters/金%20(char).md) "metal" — a transliteration of *Einstein*, after physicist Albert Einstein, continuing this vault's avoid-the-real-element-character convention (the actual Chinese chemistry character for einsteinium is 锿, āi, a dedicated element-only glyph sharing no relationship with any of this word's three constituent characters) — the same pattern as [[丹金]]/[[居里金]]/[[奥加素]]/[[田納素]]/[[莫斯素]]/[[日本素]] elsewhere in this series.

愛因 renders only the first two syllables of 愛因斯坦, the standard Mandarin transliteration of the full surname "Einstein" — truncated to two syllables here rather than spelled out in full, unlike [[居里金]] (Curie), whose transliteration was already short enough to use whole. This truncation pattern mirrors how Chinese scientific nomenclature regularly abbreviates multi-syllable transliterated names when coining single-character or short-compound element names. Mandarin/Cantonese here are the plain compositional concatenation of the three constituent characters' own readings (àiyīnjīn/oi3 jan1 gam1), not the real element name.

Japanese and Korean both borrow the IUPAC scientific name wholesale as a loanword (アインスタイニウム, 아인슈타이늄) rather than deriving it compositionally, the same pattern already established on [[居里金]] and consistent across this whole actinide-naming series regardless of which convention Mandarin/Cantonese follow. Vietnamese similarly nativizes the international name directly as Einsteini, continuing the series' "-i" ending pattern already seen on [[日本素]]'s Nihoni and [[居里金]]'s Curi. `kwin` is false, following the same AND-rule exception already documented on [[丹金]]/[[居里金]]: the authoritative test is a plain string comparison of 諺文 (애인김) against `korean` (아인슈타이늄), which plainly differ.
