## Notes
- [除](../characters/除.md) "divide" + [法 (char)](../characters/法%20(char).md) "method, operation" — literally "dividing method," the division operation.

除法 refers to division as a mathematical operation, completing the set alongside [[加法]] (addition), [[減法]] (subtraction), and [[乗法]] (multiplication) — all four built on the same X+法 pattern naming an arithmetic operation as a "method." Mandarin chúfǎ, Cantonese ceoi4 faat3, Japanese じょほう, and Korean 제법 are all standard, fully compositional terms, matching 除's and 法's own stored citations exactly. Vietnamese trừ pháp is likewise compositional (除's own Hán Việt reading trừ + 法's own pháp), though everyday Vietnamese math instruction instead uses the native phrase phép chia — the same register split already documented on [[加法]]/[[減法]]/[[乗法]], where the compositional Sino form and the living vernacular term diverge.

`kwin` is false: Dan'a'yo 제빱 diverges from Sino-Korean 제법 in the second syllable, since 法 independently carries `kwin: false` on its own character page.
