## Notes
- [紫](../characters/紫.md) "purple, violet" + [丁 (char)](../characters/丁%20(char).md) "fourth" + [香](../characters/香.md) "incense, fragrant, aroma" — none of the three characters' own `stand_in` points here (紫's is [[紫色]], 丁's is [[丁]] itself, 香's is [[香気]]), so `#cranberry` does not apply. `kwin: false` per the AND-rule: 紫 is individually `kwin: false`.

紫丁香 names the lilac (Syringa oblata) — literally "purple clove-fragrance," so named (per Ming-era scholar Gao Lian) for flowers shaped like fine nails (丁), colored purple, and fragrant (confirmed via web search).

Mandarin zǐdīngxiāng, Cantonese zi2 ding1 hoeng1, and Korean 자정향 (jajeonghyang) are all standard, fully compositional readings. Japanese むらさきはしどい (murasaki-hashidoi) is the standard Japanese name for lilac, attested for the fuller written form 紫丁香花 (with an added 花 "flower"), confirmed via web search — 紫丁香花 and 紫丁香 name the same plant. Vietnamese tử đinh hương is the standard, fully compositional Vietnamese term. No Dan'a'yo homophones.
