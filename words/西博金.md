## Notes
- [西](../characters/西.md) + [博](../characters/博.md) + [金 (char)](../characters/金%20(char).md) "metal" — a transliteration of *Seaborg*, after chemist Glenn T. Seaborg, who co-discovered ten transuranium elements and for whom this one was named while he was still living — an exception IUPAC made to its usual rule against naming elements after living people, and fittingly so given that Seaborg himself pioneered the modern actinide-series naming conventions this whole vault sub-series is patterned on. This continues the vault's avoid-the-real-element-character convention: the real Chinese chemistry name for seaborgium is built on a single dedicated glyph (釒 "metal" + phonetic 喜, read xǐ, sometimes rendered as the separate characters 金喜 where the combined glyph doesn't display), unrelated to any of this word's three constituent characters — the same pattern as [[丹金]]/[[居里金]]/[[愛因金]]/[[柏克金]]/[[美洲金]]/[[羅倫金]]/[[奥加素]]/[[田納素]]/[[莫斯素]]/[[日本素]] elsewhere in this series.

西博 renders the first two syllables of 西博格, the standard Mandarin transliteration of "Seaborg," truncated rather than spelled out in full — the same truncate-to-two-syllables pattern already established on [[愛因金]]/[[柏克金]]/[[羅倫金]]. Mandarin/Cantonese here are the plain compositional concatenation of the three constituent characters' own readings (xībójīn/sai1 bok3 gam1), not the real element name.

Japanese and Korean both borrow the IUPAC scientific name wholesale as a loanword (シーボーギウム, 시보귬), the same pattern established across this whole series. Vietnamese similarly nativizes the international name directly as Seaborgi, continuing the series' "-i" ending pattern already seen on [[日本素]]/[[居里金]]/[[愛因金]]/[[柏克金]]/[[美洲金]]/[[羅倫金]]. `kwin` is false, following the same AND-rule exception documented across this series: the authoritative test is a plain string comparison of 諺文 (세박김) against `korean` (시보귬), which plainly differ.
