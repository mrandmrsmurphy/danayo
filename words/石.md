## Notes
- [石 (char)](../characters/石%20(char).md) "rock; stone" — stand-in for [[石 (char)|石]], which cannot appear independently; for the substance specifically, see [[石頭]]

石 is 象形 of a stone lying beneath a cliff, 厂 — the same cliff-radical component already documented on [[雁]]/[[反]] earlier in this vault's history, here subsequently distorted into the modern 丆 shape (the character page's own Notes cross-reference the same distortion pattern on 叚/段/度/席). Beyond the plain substance, 石 anchors both a huge mineral/geological compound family (石灰 "quicklime," 石英 "quartz," 岩石 "rocks, crags," 鉱石 "mineral ore") and this vault's own periodic-table abbreviation prefix for lithium via [[石素]] — a Dan'a'yo-internal descriptive coinage in the same vein as [[日素]]/[[月素]]/[[火紅素]] rather than a cross-CJKV calque. The idiom 一石二鳥 ("kill two birds with one stone") is a direct calque already shared across the whole CJKV sphere and into English, one of the more transparently international idioms in this vault's corpus.

Japanese carries a single on'yomi せき (SEKI, 石油 sekiyu "petroleum," 石炭 sekitan "coal"), alongside the fully productive native 訓読み いし (ishi), the ordinary everyday word for "stone/rock." Vietnamese thạch stays mostly in learned/technical registers (thạch anh "quartz," kim cương thạch-type mineral names) rather than everyday speech, which uses the native đá for "stone" itself — the same recurring Sino-technical/native-everyday split as [[日]]/[[月]]/[[水]]/[[火]] earlier in this sweep. `kwin` is true: Dan'a'yo 석 (seg, from Middle Chinese 船母 ʑ + 昔開韻 iᴇk) coincides exactly with Sino-Korean 석. 石 shares its Dan'a'yo reading with [[惜]] ("begrudge, rue") — a coincidental convergence, unrelated in meaning. **Incidental fix**: `characters/石 (char).md`'s own `japanese_native` field had a malformed duplicate value (a scalar `いし` followed by a stray list-item line repeating the same value) — corrected to a single clean scalar.
