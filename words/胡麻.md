## Notes
- [胡](../characters/胡.md) "reckless" (here "foreign," as in [[胡瓜]]/[[胡芦]]) is separately legitimized by [[胡乱]]. [麻](../characters/麻.md) "hemp" is separately legitimized by [[大麻]]. No cranberry: neither constituent's own `stand_in` points here.

胡麻 means sesame (Sesamum indicum) — the "foreign hemp," imported from Central Asia. Not to be confused with [[亜麻]] (linseed/flax); 芝麻 is a synonymous alternate name for the same plant, recorded as an `aliases` cross-reference.

**Found and fixed several real bugs**: `羅馬字` was missing 胡's own -u- glide (homa→houma), same class as [[胡瓜]]/[[胡芦]]'s fixes — `諺文`/`注音` had already stayed correct. `mandarin` (hīma) and `cantonese` (zi1 ma2) had both been contaminated with readings belonging to the alias 芝麻 (zhīma/zi1maa4) instead of 胡麻's own compositional hú+má/wu4+maa4 — corrected to húmá/wu4maa4. `korean` held the native phrase 참깨속 ("sesame genus") instead of the real, if more literary, Sino-Korean term 호마 — corrected. Filled blank vietnamese (hồ ma, a genuine classical/medical Sino-Vietnamese term). Japanese ごま (goma, using 胡's alternate on'yomi GO + 麻's ma) was already correct — the real, standard modern word.
