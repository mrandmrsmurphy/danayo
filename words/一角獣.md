## Notes
- [一 (char)](../characters/一%20(char).md) "one" + [角 (char)](../characters/角%20(char).md) "horn" + [獣](../characters/獣.md) "beast" — literally "one-horn beast," a calque of the Western creature *unicorn* (Latin *unus* "one" + *cornu* "horn"), the same literal construction the source word itself uses.

**Content bug found and fixed**: `cantonese` had been stored as `jat1 gok3 sau3` — a reading of this word's own written form 一角獸 — but the character string actually attested as the real Cantonese word for "unicorn" is 獨角獸 (duk6 gok3 sau3, "single/alone-horn beast"), already correctly listed among this word's own `aliases:` and already correctly used for the `mandarin` field. Corrected `cantonese` to match, so both Chinese-family readings now cite the actually-used alias form rather than the transparent-but-less-common literal calque. 一角獣/いっかくじゅう is specifically the standard Japanese form (matching this word's own primary `characters:` field and its Japanese reading), while Mandarin/Cantonese instead default to the 獨角獸/独角兽 phrasing for the same creature — a real divergence in which calque variant each language actually settled on, not an error to unify.

**Real cross-linguistic conflation, documented rather than smoothed over**: `vietnamese: kỳ lân` is the practical Vietnamese equivalent in everyday use, but it is not a literal "one-horn beast" calque at all — kỳ lân is Vietnamese's own name for the native East Asian mythological creature (cognate with Chinese 麒麟, qilin/kirin), a four-legged guardian beast conceptually and iconographically distinct from the Western horse-like unicorn. Vietnamese simply reuses its own existing mythological term for the imported Western concept rather than coining a "một sừng"-type descriptive calque, a genuine terminological conflation attested directly in Vietnamese sources discussing the mismatch. `kwin` is false, the same [[一 (char)]] root-cause pattern already confirmed across every 一-initial compound checked this stretch. No homophones (注音 ㄧㄊㄍㄛㄎㄙ⼜ unique).
