## Notes
- [為](characters/為%20(char).md) "namely" — this word is itself the stand-in that legitimizes the character 為 as an independent Dan'a'yo entry.

為 means "for, because of, to act as, namely" (as in 因為 "because," 作為 "to act as," 為了 "in order to").

Mandarin wèi, Cantonese wai4, Korean 위, and Vietnamese vi (the first-listed value among 為's own citation) are all standard, fully compositional readings, matching 為's own stored citations exactly. Filled the blank `korean`/`japanese`(い, on'yomi I)/`vietnamese` fields, added `hsk_level`("1"). Removed the redundant `品詞` field. Fixed a malformed comma-joined single-string `vietnamese` value on 為's own character page (`"vi, vị, vĩ"` → a proper three-item list) while verifying this word's composition.
