鹿 is 象形 of a deer, its antlers and legs visible in the character's strokes. **Note**: `characters/鹿 (char).md` remains genuinely unperfected (blank `pos`, `## Notes` holding only two dangling CC-initial/final wikilinks, no `date-last-perfect`) — a ninth character page found in this state this sweep — flagged for the character-perfection sweep rather than rebuilt here.

**Content bug found and fixed**: the word's own `korean` field was 녹, the South Korean 두음법칙-shifted form (word-initial ㄹ regularized to ㄴ) — but per this vault's standing rule, `korean` always records the North Korean/문화어 form, which keeps the original ㄹ onset: 록. Corrected to match the character's own already-correct field — the same bug class already found on [[老]] earlier in this sweep. Once corrected, `kwin` is genuinely true: Dan'a'yo 록 (log, from Middle Chinese 來母 l + 屋一韻 uk) coincides exactly with the corrected Sino-Korean 록.

Japanese carries a single on'yomi ろく (ROKU), rare in ordinary vocabulary since everyday Japanese uses しか (shika) as the free-standing native word for a deer — the character's own stored `japanese_native: か` is a bound reading confined to compounds like 鹿の子 (kanoko, "fawn-spotted pattern"), not the ordinary standalone word. Vietnamese lộc is the reading used here — notably, lộc also carries a distinct figurative sense in Vietnamese as "fortune, blessing, prosperity" (lộc trời "heaven-sent fortune"), an extension not paralleled by the character's other CJKV readings. `注音 ㄌㄛㄎ`/`록` is also carried by [[緑]] ("green," already correctly cross-linked on both pages) — a coincidental convergence unrelated in meaning, already documented on 緑's own page as using the same North Korean 록 form for the identical reason.
