## Notes
- [解 (char)](../characters/解%20(char).md) "explain; resolve" + [析](../characters/析.md) "split, parse" — analysis, especially in a technical/mathematical sense (解析幾何 "analytic geometry," 解析学/giải tích "mathematical analysis/calculus," 数値解析 "numerical analysis"), distinct from the more general-purpose [[分析]]. Attested across all five languages: Mandarin jiěxī, Cantonese gaai2 sik1, Japanese かいせき, Korean 해석, Vietnamese giải tích.

The Knowledge page lists 解析 as "to analyze, analysis — a more technical/mathematical register than 分析," while the Mind page flags the pair [分析](分析.md) and 解析 as an undocumented near-duplicate ("analyze"). The register difference on the Knowledge page is the one distinction on record, and Dan'a'yo does not force a harder line between them. Note that 分析 is the stand-in for the character 析, so it is the word that legitimizes 析, while 解析 reads the same character under a different first element. Dan'a'yo keeps the sense "analyze, analysis." The Korean 해석 (also the usual word for "interpretation," written 解釋) differs from the Dan'a'yo 諺文 걔석 in the first syllable, so `kwin` is false. The Korean "interpretation" remark is from memory and has not been checked against a source.
