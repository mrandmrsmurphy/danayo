## Notes
- [鵖](../characters/鵖.md) + [鴔](../characters/鴔.md) — **`#cranberry`**: both 鵖's and 鴔's own `stand_in` point to [[鵖鴔]] itself, a native rhyming binome, listed on [[lookup/List of 連綿詞]].

鵖鴔 is a classical/archaic name for the hoopoe (*Upupa epops*), distinct from the modern standard Chinese name 戴勝 (dàishèng) for the same bird. Japanese ヤツガシラ ("eight-head," describing the crest) and Vietnamese đầu rìu ("axe-head," likewise describing the crest) are both real, everyday native names built on the same visual logic. Korean 핍핍 is the compositional reading; 鴔's own native gloss 오디새 correctly identifies hoopoe, though 鵖's own native gloss 상모솔새 ("goldcrest") points to an unrelated species — a discrepancy on the character page worth flagging but not resolved here.
