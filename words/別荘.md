## Etymology

## Notes
"Villa, vacation home" — a house separate from one's main residence, built for leisure (escaping summer heat, rest and recreation). `vietnamese: biệt trang` is compositional from each character's own confirmed reading; no independently attested fixed idiom was found via web search (everyday Vietnamese uses biệt thự, a different but closely related compound, for this concept), so this is documented as compositional.

**Real content bugs found and fixed**: `japanese` had a garbled string ("けしょー" — not a real reading) — corrected to べっそう (confirmed via web search). `korean` had the Chinese characters "別莊" stored instead of the actual Hangul reading — corrected to 별장 (compositional). `kwin` is false: Dan'a'yo 벋좡 diverges from Sino-Korean 별장 in the second syllable's initial consonant. No homophones (注音 ㄅㄝㄊㄐ⺢ㄫ unique among both words and characters).
