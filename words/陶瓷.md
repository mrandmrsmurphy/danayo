## Notes
- [陶](../characters/陶.md) "pottery" + [瓷](../characters/瓷.md) "porcelain" — this word is the stand-in that legitimizes 瓷 as a bound character (陶's own stand-in is [[陶器]]; transitivity fails, so no `#cranberry`).
- Real Japanese and Korean orthography spell this word 陶磁/도자, using [[磁]] instead of [[瓷]] — a historical extension of 磁's meaning from the Cizhou (磁州) kilns. Dan'a'yo keeps 磁 = magnetism and 瓷 = porcelain strictly separate (毎字明意), so this word is composed with 瓷 here; 陶磁 is recorded as an alias for the real-world spelling.

陶瓷 means ceramics or porcelain ware broadly. Mandarin 陶瓷 (táocí) and Cantonese 陶瓷 (tou4ci4) both use the exact same characters as this word's own Dan'a'yo headword. Japanese 陶磁 (とうじ) and Korean 도자 (doja) substitute 磁 for 瓷, as already documented above. Sino-Vietnamese đào sứ is compositionally correct but comparatively rare; everyday Vietnamese instead favors the native-Sino hybrid gốm sứ ("ceramic-porcelain," native gốm + Sino sứ).
