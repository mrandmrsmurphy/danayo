## Notes
- [骨 (char)](../characters/骨%20(char).md) "bone" + [盤 (char)](../characters/盤%20(char).md) "plate, tray, coiled base" — no `#cranberry`: both 骨's and 盤's own `stand_in` point to themselves; neither points here.

**Fixed a real `kwin` bug**: was `true`, but the AND-rule requires both constituents' own `kwin` true — 骨's is `false` — so the correct value is `false`.

Mandarin gǔpán, Cantonese gwat1pun4, Japanese こつばん, and Korean 골반 are all standard, fully compositional readings, using 盤's "wide flat/coiled base" sense to describe the basin-shaped pelvic bone structure. Sino-Vietnamese cốt bàn is the compositional form; everyday Vietnamese instead uses the native phrase xương chậu ("basin bone").
