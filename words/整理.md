## Notes
- [整](../characters/整%20(char).md) "orderly" + [理](../characters/理.md) "order" — no stand-in relationship applies (整's own stand-in is itself; 理's own is [[理由]]).

整理 means to straighten, arrange, order, or tidy.

Mandarin zhěnglǐ, Cantonese zing2 lei5, Japanese せいり, Korean 정리, and Vietnamese chỉnh lý (a genuine standard term) are all standard, fully compositional readings. Fixed real bugs: `諺文`/`注音` had both been contaminated (정지/ㄐㄝㄫㄐㄧ, using the wrong second syllable) instead of the correct compositional 정리/ㄐㄝㄫㄌㄧ (matching 理's own citation); `羅馬字` was already correct. This also invalidates a false homophone claim this page carried against [[精子]] (which only coincided because of the contamination) — removed; [[精子]]'s own page has been corrected accordingly and no longer claims the collision either.
