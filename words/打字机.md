## Notes
- [打](../characters/打.md) "strike, hit" + [字](../characters/字%20(char).md) "character, letter" + [机](../characters/机.md) "machine" — "machine that strikes characters." 打's own `stand_in` is [[打撃]] and 机's is [[机会]]; 字's is itself, so 打字机 is an independent compound.

打字机 is a typewriter. Mandarin dǎzìjī and Cantonese daa2 zi6 gei1 use exactly these characters, and Korean 타자기 is the same word read in Sino-Korean. Japanese does not use it in speech, calling the machine タイプライター, so the `japanese` field holds the Sino-Japanese reading of the characters. The spelling 打字機 is an alias; Dan'a'yo writes the last character with the simplified 机, as in [[机器]].

Compare [[筆]] (pen) and [[電脳]] (computer).
