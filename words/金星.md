## Notes
- [金 (char)](../characters/金%20(char).md) "gold, metal" + [星 (char)](../characters/星%20(char).md) "star" — "Venus," the second planet, named for its brightness after the metal.

Mandarin Jīnxīng, cantonese gam1 sing1, japanese きんせい, korean 금성, and vietnamese kim tinh are all directly attested standard readings — the same characters name Venus across all five languages, following the Wu Xing (五行) planetary-naming tradition shared throughout the CJKV sphere. Distinct from the classical/poetic name [[太白星]] ("evening star"), which coexists as a separate, already-perfected entry for the same planet.

Earlier Notes on this page may state a different value or a different reason.
