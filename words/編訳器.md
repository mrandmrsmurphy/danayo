## Notes
- [編](../characters/編.md) "compile, edit" + [訳](../characters/訳.md) "translate" + [器](../characters/器.md) "device" — "translating-compiling device." Their own `stand_in` values: 編's is [[編集]]; 訳's is [[翻訳]]; 器's is [[容器]]; none points here, so 編訳器 is an independent compound.

編訳器 is a compiler: a program that translates source code into machine code. Mandarin biānyìqì and Cantonese pin1 jik6 hei3 are the ordinary Chinese words, formed from 編 "compile" and 訳 "translate". Japanese says コンパイラ and Korean 컴파일러, so those two fields hold the readings of the characters. Compare [[翻訳]] (to translate) and [[程序]] (program).
