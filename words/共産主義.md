## Notes
- [共](../characters/共%20(char).md) "together" + [産](../characters/産.md) "produce, property" + [主](../characters/主.md) "master, main" + [義](../characters/義.md) "principle" — "doctrine of common property," built on [[主義]] ("-ism") as in [[社会主義]]. 産's own `stand_in` is [[生産]], 主's is [[主人]] and 義's is [[意義]]; none points here, so 共産主義 is an independent compound.

共産主義 is communism: the doctrine that productive property should be held in common and class distinctions abolished. Mandarin gòngchǎn zhǔyì, Cantonese gung6 caan2 zyu2 ji6, Japanese きょうさんしゅぎ and Korean 공산주의 use it; Vietnamese reverses the order as chủ nghĩa cộng sản. Compare [[社会主義]] (socialism) and [[民主]] (democracy).
