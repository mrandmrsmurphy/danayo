## Notes
- [単](../characters/単.md) "single" + [詞](../characters/詞.md) "word" — this word is itself the stand-in that legitimizes the character [詞](../characters/詞.md) as an independent Dan'a'yo entry (単's own stand-in is [[簡単]]).

単詞 means "word," the basic lexical unit.

Japanese たんご and Korean 단어 both use the real-world compound 単語/단어 ("single-language/speech," built with 語 rather than 詞) rather than a compositional reading of 単詞 itself — the everyday word for "word" in both languages is formed from 語, not 詞, so this is a genuine, expected divergence (`kwin: false` correctly reflects it), not an error. Vietnamese `những lời` ("the words, utterances") likewise reflects everyday usage rather than a strict compositional calque. A genuine Dan'a'yo homophone with [[丹砂]] ("cinnabar") is already documented reciprocally on both pages. No other homophones (注音 ㄉㄚㄋㄙㄚ shared only with 丹砂).
