## Notes
- [唉 (char)](../characters/唉%20(char).md) "alas (ancient)" — stand-in for [[唉 (char)|唉]], which cannot appear independently

**Open question, deliberately not resolved here**: both this word's own page and `characters/唉 (char).md` carry an unresolved note — "consider blending in with the mouth-less version" — referring to [[矣]] (mandarin yǐ), the character left over when 唉's own [[口]] "mouth" radical is removed, and named as 唉's own `graphemic_classification` phonetic component. This is very likely why this page stayed open across many prior iterations of this sweep without being touched. Checked, but did **not** decide: 矣 already has its own fully independent character page in this vault with its own distinct Dan'a'yo reading (⼔/워, from Middle Chinese 曉母 x + 皆開韻 ɣɛi) that does not match 唉's own (ㄚㄧ/애, from Middle Chinese 影母 ʔ + 咍韻 ʌi) — the two have drifted apart phonologically despite the phonetic-derivation relationship, and neither page's `aliases:` field currently lists the other. Per the standing precedent established for the [[狡]]/[[滑]] (猾) case — a character registered as another's alias is folded into the parent and never used independently, but that determination is made explicitly by the user, not assumed either way by whoever is doing word/character upkeep — this merge-or-keep-separate question is left open for the user to decide, exactly as it was before this iteration; only the surrounding fields (frontmatter, homophones, Vietnamese reading) were completed.

**Real homophone group found**: `注音 ㄚㄧ`/`애` is also carried by two other existing standalone words, [[崖]] ("cliff") and [[愛]] ("love"). Added the full mutual callout across all three pages. Checked the remaining `ㄚㄧ`-reading characters (碍, 埃, 艾, 挨, 曖, 哀, 靄) — none has a self-pointing `stand_in`, confirming no fourth homophone word exists here. `vietnamese: ai` was picked from the character's own noisy 8-item stored list (ai, hãy, hĩ, hơi, hẽ, hễ, hởi, hỡi) as the one independently confirmed via web search against Hán Việt dictionaries specifically for this "alas, lament" sense. `kwin` is true: Dan'a'yo 애 (ai) coincides exactly with Sino-Korean 애.
