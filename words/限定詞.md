## Notes
- [限](../characters/限.md) "limit, boundary" + [定](../characters/定.md) "decide" + [詞](../characters/詞.md) "word" — a grammatical term built directly on [[限定]] ("to restrict, limit") plus 詞 ("word").

限定詞 is the grammatical term for a determiner — a word class that specifies a noun's reference (articles, demonstratives, possessives, quantifiers). Mandarin 限定詞 (xiàndìngcí), Cantonese 限定詞 (haan6deng6ci4), Japanese 限定詞 (げんていし), and Korean 한정사 (hanjeongsa) all preserve the same compound order as the Dan'a'yo headword (限定 + 詞, "restriction-word"). Sino-Vietnamese linguistics instead uses từ hạn định — reversing the order to "word" + "restriction" (từ hạn định, literally "restricting word"), following the native Vietnamese noun-then-modifier pattern rather than the Chinese-order calque; this head-noun-first reordering is common in modern Vietnamese grammatical terminology coined from Sino-Vietnamese morphemes.

**Note**: 限定 (the separate word meaning "to restrict, limit") is *not* an orthographic alias of this word — it is a distinct, independently perfected headword; only 限定词 (the simplified-character form of this compound) is a genuine alias.
