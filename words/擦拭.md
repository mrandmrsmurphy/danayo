## Notes
- [擦 (char)](../characters/擦%20(char).md) "wipe, scrub, rub, scour, brush" + [拭](../characters/拭.md) "wipe" — stand-in for [[拭]], which cannot appear independently

Mandarin cāshì and Cantonese caat3 sik1 are real, written/formal-register words for "to wipe clean" (擦拭乾淨, "wipe until clean"). Vietnamese sát thức is likewise a real, attested Sino-Vietnamese compound (verified via search), though the everyday native phrase is lau chùi.

**Cross-linguistic asymmetry, disclosed rather than force-corrected — the same standard as [[男人]]/[[長牙]] earlier this sweep**: neither Japanese nor Korean appear to actually use 擦拭 as a living compound. The frontmatter values (さっしょく/sasshoku, 찰식/chalsik) are honest on'yomi/Sino-Korean-compositional readings only, corrected from the previous fields, which had substituted entirely native, unrelated verbs instead (Japanese ふく, 拭く alone; Korean 씻다, "to wash"). What each language actually says: Japanese uses native 拭く (ふく) or 拭う (ぬぐう); Korean uses native 닦다 (dakda) or 씻다 (ssitda). **`kwin` confirmed `false`**: `characters/擦 (char).md` was itself corrected `true`→`false` during this word's own #131 Swadesh turn (a real bug — its Dan'a'yo 諺文 찯 and Sino-Korean 찰 are different Hangul syllables), so the mechanical AND-rule (擦 false AND 拭 true) now directly and correctly evaluates to `false`, matching this compound's stored value — no longer a judgment call.
