## Notes
- [電子](電子.md) "electron" + [版](../characters/版.md) "edition, version"

電子版 means an electronic edition or version (of a book, document, or publication), as opposed to a print edition. Mandarin 電子版/电子版 (diànzǐbǎn), Cantonese 電子版 (din6zi2baan2), Japanese 電子版 (でんしばん), and Korean 전자판 (jeonjapan) all preserve the same compound order as the Dan'a'yo headword. Sino-Vietnamese instead uses bản điện tử — reversing the order to "edition" + "electronic," the same native noun-then-modifier pattern documented on [[限定詞]] and [[除外]].

**Found and fixed a real bug**: `羅馬字`/`諺文` had drifted to denjipan/던지판, inconsistent with 子's own correctly-stored jǝ/즈 (注音 ㄐㄜ already correct) — corrected to denjǝban/던즈판, the same recurring bug class just fixed on [[電子]] one iteration ago.
