## Notes
- [火 (char)](../characters/火%20(char).md) "fire" — stand-in for [[火 (char)|火]], which cannot appear independently

火 is a 象形 pictograph of flame, compressed to the four-dot form 灬 at the bottom of a character (though the original standalone shape survives even there in 灸, "moxibustion") — the same graphemic-compression pattern already documented for [[水]]'s 氵/氺 forms in this sweep. Beyond the literal element, 火 generates both a folklore/imagery layer (鬼火, 燐火 "will-o'-the-wisp," 火鼠 "the mythological fire rat") and a technical/scientific one, including 火星 ("Mars," continuing the Five-Phases planet-naming pattern alongside 水星/[[水]] and 木星), 火曜日 ("Tuesday," the fire-day in the Five-Phases weekday scheme), and the vault-internal periodic-table abbreviation prefix in [[火紅素]] ("strontium," literally "fire-red element," describing the metal's characteristic crimson flame test color — a genuine descriptive coinage, unlike 水銀's cross-CJKV calque).

**Content bug found and fixed**: the word's own `注音` was stored as the literal three-letter spelling `ㄏㄨㄚ`, but no syllable page exists under that string — the vault's actual canonical syllable page for this sound is `ㄏ⺢.md`, using the corpus's own single-glyph rime notation (⺢ standing in for the -ua rime, the same convention already seen throughout this sweep on 山's 「ㄍ⺢ㄋ」-type readings). Corrected to match the character's own stored `ㄏ⺢` — the same character-vs-word `注音` divergence bug class already documented multiple times elsewhere in this vault's history (屎/破/即, 恩/慣, 調/酒), now confirmed on 火 as well. `羅馬字`/`諺文` (hwa/화) were already correct and needed no change.

Japanese carries two on'yomi, か (KA, the default — 火山 kazan, 火曜日 kayōbi) and rarer こ (KO, confined to a small set of compounds), alongside the fully productive native 訓読み ひ (hi) — visible even inside rendaku'd compounds like 花火 (hanabi, "fireworks," lit. "flower-fire," where 火 surfaces as -bi). Vietnamese hoả stays in the learned/technical register (hoả tiễn "rocket," hoả hoạn "fire disaster") while everyday speech uses the native lửa for "fire" itself — the same Sino-technical/native-everyday split already seen on [[日]]/[[月]]/[[水]] earlier in this sweep. `kwin` is true: Dan'a'yo 화 (hwa, from Middle Chinese 曉母 x + 戈一合韻 uɑ) coincides exactly with Sino-Korean 화.
