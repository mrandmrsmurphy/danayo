## Notes
- [美 (char)](../characters/美%20(char).md) + [洲 (char)](../characters/洲%20(char).md) "continent" (as in [[美洲]] "the Americas") + [金 (char)](../characters/金%20(char).md) "metal" — *Americium* is named directly after the Americas, by analogy with europium (element 63, named after the continent Europe), continuing this vault's avoid-the-real-element-character convention (the actual Chinese chemistry character for americium is 镅, méi, unrelated to any of this word's three constituent characters) — the same pattern as [[丹金]]/[[居里金]]/[[愛因金]]/[[柏克金]]/[[奥加素]]/[[田納素]]/[[莫斯素]]/[[日本素]] elsewhere in this series.

Unlike most of the actinides discovered at Berkeley — which transliterate a scientist's surname, as [[愛因金]] (Einstein) and [[柏克金]] (Berkeley) both do — this one calques the etymology directly rather than transliterating anything, the same "named after a place, not a person" logic already used for [[日本素]] (Nihonium, "named after Japan"). Mandarin/Cantonese here are the plain compositional concatenation of the three constituent characters' own readings (měizhōujīn/mei5 zau1 gam1), not the real element name.

Japanese and Korean both borrow the IUPAC scientific name wholesale as a loanword (アメリシウム, 아메리슘), the same pattern established across this whole series regardless of whether the underlying name is a calque or a transliterated surname. Vietnamese similarly nativizes the international name directly as Americi, continuing the series' "-i" ending pattern already seen on [[日本素]]/[[居里金]]/[[愛因金]]/[[柏克金]] — notably, the pattern holds here even though the name itself is a calque rather than a personal-name transliteration, since Vietnamese (like Japanese/Korean) borrows the international scientific name wholesale regardless of its underlying etymology. `kwin` is false, following the same AND-rule exception already documented across this series: the authoritative test is a plain string comparison of 諺文 (미줏김) against `korean` (아메리슘), which plainly differ.
