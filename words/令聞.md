## Notes
- [令 (char)](../characters/令%20(char).md) "good, fine" (honorific adjective sense) + [聞 (char)](../characters/聞%20(char).md) "to hear, reputation" — "good name, fame," directly attested Sino-Vietnamese lệnh văn (confirmed via web search), part of the same honorific-adjective family as lệnh danh ("good reputation") and lệnh đức ("good virtue"). **Real gap found and fixed on [[令 (char)]]'s own page**: its `vietnamese` field was missing this honorific-adjective reading lệnh entirely (as well as the causative verb reading linh, "to cause, to order") — both added. Removed a duplicate `品詞` key (redundant with `pos`). `kwin` is false: Dan'a'yo 렁문 diverges from the correct compositional Sino-Korean 령문 in the first syllable's initial consonant. No homophones (注音 ㄌㄝㄫㄇㄨㄋ unique among both words and characters).

**Real content bug found and fixed**: `korean` had been set to the South-Korean 두음법칙-shifted form 영문 (coincidentally homophonic with 英文, "English text") instead of the vault's standard unshifted North-Korean 령문, compositional from 令's own 령 + 聞's own 문 — the same bug pattern just found on [[令圄]]. Removed a dangling empty `swadesh: ""`.
