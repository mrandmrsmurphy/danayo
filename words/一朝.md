## Notes
- [一 (char)](../characters/一%20(char).md) "one" + [朝 (char)](../characters/朝%20(char).md) "morning" — literally "one morning," hence "a short time, a brief moment" — the same "single sunrise-to-sunrise span" logic behind English "overnight" as a byword for suddenness.

**Structural fix**: the plain-text line "Homophones: [[一兆]] - one trillion" sitting before the `meta-bind-embed` block violated both the meta-bind-embed-must-come-first rule and the checklist's required callout format — converted to a proper `>[!warning] Homophones` callout (the reciprocal callout on [[一兆]]'s own page has the same issue, flagged here rather than fully fixed since perfecting 一兆 itself is a separate task in this backlog).

朝 carries two distinct Vietnamese readings by sense — triêu ("morning," used here) versus triều ("royal court, dynasty," as in triều đình) — the same character splitting by meaning the way [[行]] (xíng/háng) did earlier in this sweep. `vietnamese: nhất triêu` (confirmed via web search) picks the morning-sense reading matching this word's own "short time" gloss, not the dynastic one. `kwin` is false, following the now-familiar [[一 (char)]] root-cause pattern: 一's own Dan'a'yo 읻 retains the MC checked coda that Sino-Korean's 일 has regularized away, already fixed at the character level and now propagating correctly to every 一-initial compound checked in this stretch of the sweep ([[一定]]/[[一斉]]/[[一旦]]/一朝, all `kwin: false` for the identical reason).
