## Notes
- [具](../characters/具.md) "tool, instrument" + [格 (char)](../characters/格%20(char).md) "case (grammatical)" — the grammatical case marking the means/instrument by which an action is performed ("with, by means of"), paralleling [[共格]] (comitative case) as a matched pair of case-term coinages in this vault. `vietnamese: cụ cách` is compositional; like [[共格]], Vietnamese linguistics has no independent tradition of naming this specific case (a minimally case-marked language), so no fixed attestation was found via web search — documented as compositional.
