## Notes
- [連 (char)](../characters/連%20(char).md) "consecutive, link" + [邦](../characters/邦.md) "nation, state" — "federation, federal state, commonwealth, union."

Mandarin liánbāng, cantonese lin4 bong1, japanese れんぽう, korean 연방, and vietnamese liên bang are all directly attested standard readings, matching both characters' own stored values exactly. `聯邦` is a legitimate spelling variant using 連's own alias character 聯 (per this vault's explicit policy, documented on 連(char).md, of officially merging 聯/联 into 連 — hence 連邦, not 聯邦, as the primary form).

Both character-page citations already correctly present. 邦's own `stand_in` is this exact word (連邦), so 邦 is legitimized as an independent Dan'a'yo entry specifically by 連邦; 連's own `stand_in` is instead 連 itself, so this word does not legitimize 連.

Earlier Notes on this page may state a different value or a different reason.
