## Notes
- [羅](../characters/羅.md) + [倫](../characters/倫.md) + [金 (char)](../characters/金%20(char).md) "metal" — a transliteration of *Lawrence*, after physicist Ernest Lawrence, inventor of the cyclotron and founder of the Lawrence Berkeley National Laboratory where the element was discovered, continuing this vault's avoid-the-real-element-character convention (the actual Chinese chemistry character for lawrencium is 铹, láo, unrelated to any of this word's three constituent characters) — the same pattern as [[丹金]]/[[居里金]]/[[愛因金]]/[[柏克金]]/[[美洲金]]/[[奥加素]]/[[田納素]]/[[莫斯素]]/[[日本素]] elsewhere in this series.

羅倫 renders the standard Mandarin transliteration of the surname "Lawrence" (as in 勞倫斯/羅倫斯), truncated to two syllables — the same truncate-to-two-syllables pattern already established on [[愛因金]] (Einstein) and [[柏克金]] (Berkeley), all three named for Berkeley-connected physicists or institutions. Mandarin/Cantonese here are the plain compositional concatenation of the three constituent characters' own readings (luólúnjīn/lo4 leon4 gam1), not the real element name.

Japanese and Korean both borrow the IUPAC scientific name wholesale as a loanword (ローレンシウム, 로렌슘), the same pattern established across this whole series. Vietnamese similarly nativizes the international name directly as Lawrenci (also attested as Lorenxi/Lorenci in some sources), continuing the series' "-i" ending pattern already seen on [[日本素]]/[[居里金]]/[[愛因金]]/[[柏克金]]/[[美洲金]]. `kwin` is false, following the same AND-rule exception documented across this series: the authoritative test is a plain string comparison of 諺文 (로룬김) against `korean` (로렌슘), which plainly differ.
