## Notes
- [日 (char)](../characters/日%20(char).md) "sun" + [素](../characters/素.md) "element, stuff" — "sun element," helium.

日素 is the Dan'a'yo name for helium (He), built on the same etymology as the English word: helium takes its name from Greek *helios*, "sun", because it was first detected in the solar spectrum. The Dan'a'yo name avoids the Chinese novel characters 氦 and 氜 and instead builds from 日 "sun" plus the element classifier 素. It is a Dan'a'yo-internal coinage with no CJKV precedent, since none of the source languages uses 日 for helium. For the full system of element names, see [Periodic Table](../lexipedia/Periodic%20Table.md).

The recorded readings are the languages' own names for the element rather than compositional readings of 日素: Mandarin hài (氦), Cantonese hoi6, Japanese ヘリウム (heriumu), Korean 헬륨 (hellyum), and Vietnamese heli.
