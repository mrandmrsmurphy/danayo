## Notes
- [休](../characters/休.md) "rest" + [息](../characters/息.md) "tell news, breathe" + [室](../characters/室.md) "room" — because [[休息]] is an attested vault word and 休憩 isn't, this headword follows 休息室 (Chinese) over 休憩室 (Japanese and Korean).

The character composition follows real Mandarin usage (休息室, xiūxíshì, "break room"), while `japanese: きゅうけいしつ` and `korean: 휴게실` instead document each language's own real everyday word for this concept — which happens to be built from the near-synonymous 休憩室 rather than 休息室 itself (per the note above, chosen because [[休息]] is already an attested vault word while 休憩 is not). `vietnamese: phòng nghỉ` follows the same pattern: no fixed idiom "hưu tức thất" was found attested via web search, so the everyday native Vietnamese phrase is used instead. Filled the blank `cantonese: jau1 sik1 sat1`, compositional. `kwin` is false: Dan'a'yo 휴식싣 diverges entirely from the 休憩室-based Korean field. No homophones (注音 ㄏ⼜ㄙㄧㄎㄙㄧㄊ unique among both words and characters).
