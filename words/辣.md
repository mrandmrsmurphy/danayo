## Notes
- [辣 (char)](characters/辣%20(char).md) "spicy, hot, cruel" — 辣 stands alone as a word in Dan'a'yo.

Mandarin là, cantonese laat6, and korean 랄 are all directly attested standard readings, matching the character's own stored values exactly. Vietnamese lạt is likewise the character's own stored reading. **Found and fixed a `kwin` miscalculation on 辣(char).md itself**: it stored `kwin: true`, but byte-level comparison shows Dan'a'yo 랃 (U+B783) and Sino-Korean 랄 (U+B784) are visually near-identical but genuinely different Hangul syllables — the same class of divergence bug found elsewhere this session (cf. 읫/의, U+C76B vs U+C758). Corrected to `kwin: false` on both pages. No homophones among independently-attested words (注音 ㄌㄚㄊ is also shared by 剌, but it has no dedicated word page).

辣 (char)'s own `stand_in` is this exact word (辣, itself), so 辣 (char) is legitimized as an independent Dan'a'yo entry by this same word.
