## Notes
- [今 (char)](../characters/今%20(char).md) "now" + [晩 (char)](../characters/晩%20(char).md) "evening" + [安](../characters/安.md) "peace, well-being" — "good evening" (an arrival greeting), the evening-hours counterpart to [[今昼安]] ("good day") and distinct from [[今夜安]] ("good night," a bedtime/parting farewell) — the same arrival/departure distinction English draws between the two. Same Dan'a'yo-internal coinage pattern: no real Mandarin/Cantonese/Japanese/Korean compound is built from these same three characters, so each language field instead documents that language's own real evening arrival greeting: 晚上好/wǎnshàng hǎo (matching the alias now stored)/maan5 soeng6 hou2, こんばんは (structurally parallel to Japanese's own こんにちは), 안녕하세요 (Korean, like English, doesn't distinguish "good day" from "good evening" in its all-purpose greeting), and chào buổi tối.
