## Notes
- [[燐]] "phosphorus" + [[素]] "element" — stand-in for [[燐]], which cannot appear independently.

**Form.** Unlike [[塩素]] and [[炭素]] (real, established compositional words), 燐素 is a `neologism`: no language in the Sinosphere actually names phosphorus with an X+素 compound. `mandarin`/`cantonese`/`korean`/`japanese` above give the real single-morpheme names for the element in each language — not readings of 燐素 as a two-character compound — per the same convention already established for [[巨金]]/[[惰素]].

**Comparative CJKV forms.** Mandarin uses 磷 (lín) — a distinct standard element character (stone radical 石) from 燐 (fire radical, meaning "phosphorescence, will-o'-the-wisp" rather than the element itself), though the two share the phonetic component 粦 and the same reading. Cantonese leon4 follows the same single-character pattern. Japanese uses リン (rin), katakana rather than kanji since 燐 is a hyōgai (non-standard) character — paralleling how sulfur is 硫黄 (iō) rather than a constructed "硫素." Korean uses 린 (rin) — the North Korean/문화어 form, per this vault's standing convention; South Korean orthography would shift this to 인 via 두음법칙 (word-initial ㄹ→ㅇ before ㅣ/y-glide vowels, the same rule affecting 李→이, 龍→용), but that shift is deliberately not reflected here. Vietnamese photpho is a direct phonetic loan from the international name, not a compositional Sino-Vietnamese form.

**Conclusion.** 燐素 is a vault-internal compositional coinage — 燐 ("phosphorescence," here narrowed to mean the element itself) + 素 ("element") — that does not correspond to real usage in any daughter language, structurally the same situation as this sweep's other invented periodic-table names rather than the 塩素/炭素 real-word case.
