## Notes
- [緑 (char)](../characters/緑%20(char).md) "green" + [柱](../characters/柱%20(char).md) "pillar" + [素](../characters/素.md) "element, stuff" — "beryl element," beryllium.

緑柱素 is the Dan'a'yo name for beryllium (Be), built on the same etymology as the English word: beryllium takes its name from the mineral beryl, which the element was first isolated from. 緑柱 is the stem of 緑柱石, the Chinese and Japanese name for beryl ([[緑柱石]], "green pillar stone"), and 素 is the element classifier. It is a Dan'a'yo-internal coinage that avoids the Chinese novel character 铍. The character 緑 is also used as the periodic-table prefix for beryllium. For the full system of element names, see [Periodic Table](../lexipedia/Periodic%20Table.md).

The recorded readings are the languages' own names for the element rather than compositional readings of 緑柱素: Mandarin pí (铍), Cantonese pei4, Japanese ベリリウム (beririumu), Korean 베릴륨 (berilryum), and Vietnamese berili.
