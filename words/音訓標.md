## Notes
- [音](../characters/音.md) "sound" + [訓](../characters/訓%20(char).md) "interpret, gloss" + [標](../characters/標.md) "mark, sign" — "the sound-and-gloss mark".

Wiktionary has no entry for 音訓標; it is a **Dan'a'yo coinage** for the line of phonetic transcription written above each character, the ruby. In [[文法 - 03文字法]] the heading is `## 音訓標`, and the chapter says that above each character appears 音訓標 in [[注音符号]] letters, set in 振り仮名 style, showing the intended pronunciation directly. Like [[関詞]], [[派生辞]] and [[接頭辞]], its language fields give the literal readings of its own characters 音 + 訓 + 標, not an existing native term for ruby.

The name calls the ruby the mark of a character's reading: 音 "sound", 訓 "interpret, gloss" and 標 "mark, sign" ([[標識]]). Dan'a'yo's ruby records a single reading, in line with 【[[一字一音]]】 (every character has one and only one pronunciation); the chapter does not explain the 訓. The notation system is [[注音]], the script [[注音符号]], and 音訓標 is the role, the annotation line.
