## Notes
- [交 (char)](../characters/交%20(char).md) "to exchange, interact" + [接 (char)](../characters/接%20(char).md) "to receive, connect" — directly attested Sino-Vietnamese (confirmed via web search), giao tiếp is everyday Vietnamese for "to communicate, interact" (kỹ năng giao tiếp, "communication skills"), matching this word's own "link, join, connect" senses. The euphemistic "have intercourse" sense parallels the same semantic extension found in the Mandarin original.
