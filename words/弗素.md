## Notes
- [弗](../characters/弗.md) "fluorine" + [素](../characters/素.md) "element" — literally "fluorine-element," fluorine — stand-in for [弗](../characters/弗.md), which cannot appear independently. Real Chinese instead coins a single novel character (气 "gas" radical + 弗 phonetic, i.e. 氟, stored as 弗's own alias) for this element, a pattern Dan'a'yo deliberately avoided by borrowing the real Japanese two-morpheme convention (弗素/ふっそ) instead.

Japanese ふっそ (fusso) is the real, standard Japanese word, following the same 素-suffixed pattern used for every other halogen/gas element in Japanese (塩素, 酸素, 水素, 窒素, etc.). Korean 불소 is likewise a real, standard Sino-Korean compound built the same way, and — unusually among these periodic-table words — is genuinely compositional: 弗's own Sino-Korean 불 + 素's own 소. Mandarin and Cantonese, by contrast, are stored as the real bare words (fú/fat1, matching 弗's own stored citations exactly, since 氟 shares 弗's phonetic reading) rather than a compositional "fúsù"/"fat1 sou3" — Chinese has no such 素-suffixed halogen convention, only single novel characters. Vietnamese flo is an unrelated French/international loanword.
