## Notes
- [太 (char)](../characters/太%20(char).md) "extremely, too" + [様 (char)](../characters/様%20(char).md) (adverbial suffix) — "greatly, exceedingly." Japanese 迚も is an unusual kanji rendering (当て字) of とても "very," an ad-hoc match rather than this compound's genuine on'yomi reading. Filled blank `pos: 副詞`. **Important collision caveat**: filled `korean: 태양` and `vietnamese: thái dạng`, both compositional — but 태양 is an EXACT match for [[太陽]]'s own real Korean reading ("sun"), the same collision already flagged via the Dan'a'yo-level homophone callout above; this is not independently attested as a real Korean adverb (domain knowledge, this session's search quota exhausted). `kwin` is true: Dan'a'yo 태양 matches the compositional Sino-Korean 태양 exactly — unsurprising, since this word's Dan'a'yo pronunciation is itself identical to [[太陽]]'s. Treat this compositional korean value with the same caution as the vietnamese one, since neither is independently attested as real usage for this sense.
