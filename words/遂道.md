## Notes
遂道 is this vault's own deliberate spelling using 遂 in place of the semantically-equivalent 隧 ("tunnel, underground passage") — 遂's own `aliases` field explicitly registers 隧 as folding into 遂, and 遂's own page documents this merge directly ("used as 遂 in [[遂道]], the Dan'a'yo form of 隧道"). `隧道`, the standard real-world spelling, is correctly listed as an alias.

Mandarin suìdào, cantonese seoi6 dou6, japanese ずいどう, and korean 수도 are all directly attested standard readings, matching both characters' own stored values exactly.

Both character-page citations already correctly present. Neither 遂's `stand_in` (既遂) nor 道's own `stand_in` (道 itself) points to this compound.
