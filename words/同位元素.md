## Notes
- [同](../characters/同.md) "same" + [位](../characters/位.md) "position" + [元](../characters/元.md) "element, origin" + [素](../characters/素.md) "element, plain thing" — isotope.

同位元素 is an isotope: one of several forms of an element with the same number of protons but different numbers of neutrons, so the same chemical identity but a different [[質量数]]. The name means "same-position element," the position being the one the element occupies in the periodic table ([[週期表]]). Japanese also says 同位体 (どういたい) and Mandarin 同位素 (tóngwèisù), shorter forms of the same idea. Mandarin tóngwèiyuánsù, Cantonese tung4 wai2 jyun4 sou3, Japanese どういげんそ and Korean 동위원소 are the readings of the full form.
