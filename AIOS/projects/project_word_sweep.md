Per-iteration procedure: read the word file, read each constituent's own `characters/` page, verify `羅馬字`/`諺文`/`注音` are the exact concatenation of each constituent's own stored values (never sound-shifted, see [[feedback_word_pronunciation_derivation]]), determine cranberry status (`#cranberry` only when *all* constituents' own `stand_in` point to this exact compound — transitivity, not just one), compute `kwin` via strict AND across constituents' own stored `kwin`, fill/fix blank or buggy cross-linguistic fields, run the scratchpad `homophone_check.py` script (3 positional args: romaji, hangul, zhuyin — scans both `words/` and `characters/`), then log the iteration and advance the pointer.
  - **Recurring bug taxonomy found across this sweep** (see [[feedback_word_bug_taxonomy]] for the full list with examples): internal-reading bugs (a single field among `羅馬字`/`諺文`/`注音` drifts from a constituent's own stored value while the other two stay correct — voicing/place-of-articulation confusion is the most common shape); cross-linguistic-field bugs, a distinct check from the internal-reading one — a real-language field (`cantonese`/`japanese`/`korean`/`vietnamese`) holds a native gloss, an unrelated synonym's reading, or garbled/wrong-language text instead of the real compositional or attested reading; and structural bugs (missing `kwin`, empty-string fields, literal string `"null"`, comma-joined values needing YAML lists, bare/unquoted `characters:` entries citing a redlink instead of the real `X (char).md` filename, stray cantonese spacing — established convention this sweep is **no space** between jyutping syllables in a compound field, e.g. `zat1man6` not `zat1 man6`). A constituent character's own page can itself hold a wrong real-language reading (found on 買's and 与's own `vietnamese` fields this sweep) — worth fixing in passing, not just the word being perfected. Constituent character pages inherited from old batches sometimes have structurally malformed `## Words`/`## Chengyu` sections (orphaned CC-lookup wikilinks dangling mid-list, ordinary compound words mislabeled under a `## Chengyu` heading) — same "old batch, worse format" pattern documented for Stroke/Chengyu/Syllables lints above; fixed in passing when touched.
