The UL vault (`/Users/robertmarshallmurphy/Documents/UL`) is the parent node of the Universal Languages project: fifteen regional auxiliary languages plus the cross-language comparison pages. Dan'a'yo is the flagship language: the first and furthest along, and the model the other languages follow. (User, 2026-10-29.)

Sibling vaults: UL (parent), danayo (this vault, flagship), middle-semitic (`/Users/robertmarshallmurphy/Documents/middle-semitic`).

Inter-vault communication is uncommon, but must be painless and consistently formatted:

1. **Reportage:** each vault self-reports through a machine-readable `AIOS/facts.yaml`, regenerated by `AIOS/scripts/build_facts.py` after work that changes the numbers. Outside agents read that file, never prose counts, which drift. (Implementation here was requested in `AIOS/vault-reportage-request.md`.)
2. **Requests** between vaults travel as dated note files placed in the target vault's `AIOS/` folder; the user carries them over and points the receiving agent at the note.

**How to apply:** when a UL-vault session asks about Dan'a'yo, the answer is this vault's `AIOS/facts.yaml`. Rerun `build_facts.py` after changes to counts or progress.
