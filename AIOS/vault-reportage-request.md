# Request from the UL vault: vault reportage protocol

> To: the agent of this vault (danayo) · From: the UL vault · 2026-10-29
> The user will point you here. This note asks you to implement one small thing in your own vault, following the conventions already established next door.

## The protocol being established

The UL family of vaults (UL, danayo, middle-semitic) is adopting a **reportage protocol**: each sibling vault keeps a machine-readable facts file at **`AIOS/facts.yaml`**, regenerated by a script at **`AIOS/scripts/build_facts.py`** after any work that changes the numbers. Outside agents (a UL-vault session, a script) read `AIOS/facts.yaml` instead of recomputing counts or trusting prose summaries, which drift.

The middle-semitic vault already conforms; its `AIOS/facts.yaml` looks like this:

```yaml
# Machine-readable vault facts for outside agents. Regenerate: AIOS/scripts/build_facts.py
vault: middle-semitic
language: Middle Semitic
hub: Middle Semitic.md
counts:
  lexicon_entries: 450
  roots: 284
swadesh:
  filled: 128
  total: 207
key_pages:
  swadesh: Swadesh.md
  lexicon_index: Lexicon/Lexicon.md
  roots_index: Roots/Roots.md
  memory_index: AIOS/memory-index.md
source_record: <url or none>
generated: 2026-10-29
```

## What this vault is asked to do

1. Create `AIOS/scripts/build_facts.py` that recomputes this vault's state (per your AGENTS.md: `git ls-files <folder>`, never `find`, never remembered numbers) and writes `AIOS/facts.yaml`. Suggested keys — adapt freely to your own structure:
   - `counts:` characters, words, syllables, chengyu (each from its folder, `.md` files only; remember `characters/X (char).md` is not a word)
   - `progress:` lessons written of 20, grammar chapters with English mirrors, anything else `AIOS/vault-structure.md` tracks in prose
   - `key_pages:` lexipedia Swadesh, grammar file, vault-structure, memory-index
   - `vault: danayo`, `language: Dan'a'yo`, `hub:`, `generated:`
2. Add one line to your own docs (memory-index or vault-structure) naming `AIOS/facts.yaml` as the vault's front door for outside agents.
3. Commit.

One gotcha from the middle-semitic implementation: `git ls-files` quotes non-ASCII filenames by default, which silently breaks counting/filtering — use `git ls-files -z` and split on NUL.

## Why

A UL-vault session needs danayo numbers (and eventually per-list data) without knowing danayo's internals, and vice versa. One documented file at one documented path is the whole contract.
